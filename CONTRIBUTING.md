# Contributing to TeamOfAgents

Thank you for your interest in contributing to **TeamOfAgents**!

This project is a production-ready, single-file HTML experience for multi-agent orchestration. We welcome contributions that improve the wizard, add new features, enhance the UI, or help with backend proxy integrations.

## How to Contribute

1. **Fork** the repository
2. **Clone** your fork locally
3. Create a new branch for your feature/fix
4. Make your changes
5. Test thoroughly (open `index.html` in multiple browsers)
6. Submit a **Pull Request**

## What We're Looking For

- Improvements to the 5-step wizard UX
- Better LangGraph-style visualizations
- Enhancements to the real backend proxy flow
- Accessibility improvements (WCAG)
- Mobile responsiveness tweaks
- Documentation improvements

## Code Style

- Keep everything in a single `index.html` when possible
- Use Tailwind via CDN
- Maintain the existing dark glassmorphism aesthetic
- Comment complex JavaScript clearly

## Reporting Issues

Please use the GitHub Issues tab and include:
- Steps to reproduce
- Expected vs actual behavior
- Browser and device info
- Screenshots if applicable
